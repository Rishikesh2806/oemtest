<analysis>**original_problem_statement:** The user wants to build a full-stack web application called **OEMLinker** (originally MachinoMatch), an AI-driven on-demand manufacturing marketplace. The core functionality involves buyers uploading RFQs with engineering drawings. An AI engine analyzes these drawings to extract technical specifications (now geometry-aware), which a smart matching algorithm uses to connect buyers with suitable manufacturing vendors based on capabilities, dimensions, and location.

The platform must support a complete workflow: RFQ -> AI Analysis -> Vendor Matching -> Quotation -> Purchase Order -> Delivery -> Payment. It should handle different user roles (Buyer, Vendor, Admin) and include features like a vendor capability database, dashboards for each role, and a secure escrow payment system.

**PRODUCT REQUIREMENTS:**
-   **User Roles:** Buyer, Vendor, Admin.
-   **AI Core:** An Intelligence Engine to read drawings (PDF, CAD, etc.), extract technical specifications, and use RFQ title/description as a fallback.
-   **Matching:** A smart algorithm to match RFQs to vendors based on machine type, capacity, location, and past project experience.
-   **Workflow:** A complete RFQ-to-payment lifecycle management module.
-   **Security:** Secure user authentication with 2FA, password policies, and rate limiting.
-   **Commercials:** Escrow payments, platform commissions, and currency support (now INR).
-   **Dashboards:** Dedicated dashboards for buyers, vendors, and admins.
-   **Tech Stack:** React frontend, Python (FastAPI) backend, and a MongoDB database.

**User's preferred language**: English

**what currently exists?**
The OEMLinker application is a mature full-stack platform with a React frontend, a monolithic FastAPI backend, and a MongoDB database.

**Key Implemented Features:**
-   **Core Platform:** Full JWT authentication (login, register, 2FA, password reset), user role management, and dashboards.
-   **RFQ Workflow:** Users can create RFQs, upload multiple drawings (PDF/Image for analysis, CAD as attachments), and receive AI-driven analysis of specifications. The system supports upload cancellation.
-   **Advanced Vendor Matching:** The algorithm matches vendors based on a weighted score considering:
    -   Machine capabilities vs. part geometry/requirements.
    -   Dimensional/weight capacity.
    -   **Location Preferences:** Prioritizes vendors in the buyer's preferred cities.
    -   **Past Experience:** A significant matching component that scores vendors based on keywords, part types, materials, and industries from their project history.
    -   **Text-Based Fallback:** Uses RFQ title and description to infer dimensions and processes if drawing analysis is inconclusive.
-   **Vendor Profiles:** Vendors can manage their company details and add a portfolio of Past Experiences to improve their match potential.
-   **UI/UX:** The UI has been updated to use INR (₹) as the currency. It features a hybrid city selector that auto-loads Indian cities, highlighting those with registered vendors. It also provides clear user feedback on drawing analysis status (analyzed vs. CAD attachment).
-   **Admin:** A secure, one-time endpoint () exists to create the initial admin user in a new production environment.
