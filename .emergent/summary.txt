<analysis>**original_problem_statement:** The user wants to build a full-stack web application called **Offoadex.com**, an AI-driven on-demand manufacturing marketplace. The core functionality involves buyers uploading RFQs with engineering drawings (PDF, STEP, etc.). An AI engine should analyze these drawings to extract technical specifications like dimensions, tolerances, and materials. This data is then used by a smart matching algorithm to connect buyers with the most suitable manufacturing vendors based on their machine capabilities, certifications, and past work.

The platform must support a complete workflow: RFQ -> AI Analysis -> Vendor Matching -> Quotation -> Purchase Order -> Delivery -> Payment. It should handle different user roles (Buyer, Vendor, Admin) and include features like a vendor capability database, dashboards for each role, and a secure escrow payment system.

**PRODUCT REQUIREMENTS:**
-   **User Roles:** Buyer, Vendor, Admin.
-   **AI Core:** An Intelligence Engine to read drawings (PDF, CAD, etc.) and extract dimensions, tolerances, materials, and required manufacturing processes.
-   **Matching:** A smart algorithm to match RFQs to vendors based on machine capability, material, tolerance, and other factors.
-   **Workflow:** A complete RFQ-to-payment lifecycle management module.
-   **Commercials:** Escrow payments, platform commissions, and multi-currency support.
-   **Dashboards:** Dedicated dashboards for buyers, vendors, and admins.
-   **Tech Stack:** React/Next.js frontend, Python (FastAPI) backend, and a PostgreSQL database.

**User's preferred language**: English

**what currently exists?**
A full-stack application with a React frontend and FastAPI backend using MongoDB. The application has been rebranded to **Offloadex** with a new logo. It supports JWT authentication for Buyer, Vendor, and Admin roles.

Core implemented features include:
-   **RFQ Matching:** A comprehensive algorithm that validates machine dimensions, uses keyword matching, and considers vendor experience.
-   **Quotation Workflow:** Vendors can submit quotes, and buyers can view, compare, and accept them. A Quote Comparison UI has been implemented.
-   **Order Management:** Accepting a quote generates a PO. Order status tracking is implemented.
-   **Payment Terms:** A full workflow for proposing and finalizing payment terms from RFQ to Purchase Order.
-   **Vendor Rating System:** Buyers can rate vendors after an order is completed, and ratings are displayed on vendor profiles.
-   **Admin Panel:** Full CRUD management of users, vendors, RFQs, etc.
-   **Vendor/Buyer Dashboards:** Role-specific dashboards with dedicated pages for managing RFQs (e.g., My RFQs for buyers, Matched RFQs for vendors).
-   **AI & Comms:** GPT-5.2 for drawing analysis and Resend for email notifications.
