<analysis>**original_problem_statement:** The user wants to build a full-stack web application called **OEMLinker**, an AI-driven on-demand manufacturing marketplace. The core functionality involves buyers uploading RFQs with engineering drawings. An AI engine analyzes these drawings to extract technical specifications, which a smart matching algorithm uses to connect buyers with suitable manufacturing vendors based on capabilities, dimensions, and location.

The platform must support a complete workflow: RFQ -> AI Analysis -> Vendor Matching -> Quotation -> Purchase Order -> Delivery -> Payment. It should handle different user roles (Buyer, Vendor, Admin) and include features like a vendor capability database, dashboards for each role, and a secure escrow payment system.

**PRODUCT REQUIREMENTS:**
-   **User Roles:** Buyer, Vendor, Admin.
-   **AI Core:** An Intelligence Engine to read drawings (PDF, CAD, etc.), extract technical specifications, and use RFQ title/description as a fallback.
-   **Matching:** A smart algorithm to match RFQs to vendors based on machine type, capacity, location, and past project experience.
-   **Workflow:** A complete RFQ-to-payment lifecycle management module.
-   **Security:** Secure user authentication with 2FA, password policies, and rate limiting.
-   **Commercials:** Escrow payments, platform commissions, and currency support (INR).
-   **Dashboards:** Dedicated dashboards for buyers, vendors, and admins.
-   **Tech Stack:** React frontend, Python (FastAPI) backend, and a MongoDB database.

**User's preferred language**: English

**what currently exists?**
OEMLinker is a comprehensive full-stack application featuring a React frontend, a monolithic FastAPI backend, and a MongoDB database.

**Key Implemented Features:**
-   **Core Platform:** JWT authentication (login, register, 2FA, password reset), user roles, and dashboards.
-   **Email Verification:** New users receive a verification email upon registration, and a banner is displayed in the dashboard until their email is verified.
-   **RFQ Workflow:** Buyers can create RFQs, upload multiple drawings, cancel uploads, and now specify an **Urgency Status** (Normal, Urgent, Critical).
-   **Advanced Vendor Matching:** A sophisticated algorithm matches vendors based on machine capabilities, dimensions, location, and Past Experience.
-   **Vendor Profiles:** Vendors can manage company details, a portfolio of Past Experiences, and now set the **availability status** (Available, Engaged, Maintenance, Offline) for each of their machines.
-   **AI Voice Agent:** A web-based voice assistant on the vendor dashboard allows vendors to query for open RFQs using natural language in English and multiple Indian languages.
-   **Admin Notifications:** The admin () receives email notifications for key events like new user sign-ups, RFQ creation, vendor matching, new quotations, and purchase order creation.
-   **GSTIN Verification:** Vendor registration includes a verification step using a paid, third-party API to auto-fill company details from a GSTIN.
-   **UI/UX:** The application uses INR (₹) as its currency. The UI includes a new 320x80 logo and a mobile-responsive, accessible popup for the voice agent.
