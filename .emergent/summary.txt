<analysis>**original_problem_statement:** The user wants to build a full-stack web application called **MachinoMatch** (originally Offloadex.com), an AI-driven on-demand manufacturing marketplace. The core functionality involves buyers uploading RFQs with engineering drawings (PDF, STEP, etc.). An AI engine should analyze these drawings to extract technical specifications. This data is then used by a smart matching algorithm to connect buyers with the most suitable manufacturing vendors.

The platform must support a complete workflow: RFQ -> AI Analysis -> Vendor Matching -> Quotation -> Purchase Order -> Delivery -> Payment. It should handle different user roles (Buyer, Vendor, Admin) and include features like a vendor capability database, dashboards for each role, and a secure escrow payment system.

**PRODUCT REQUIREMENTS:**
-   **User Roles:** Buyer, Vendor, Admin.
-   **AI Core:** An Intelligence Engine to read drawings (PDF, CAD, etc.) and extract technical specifications.
-   **Matching:** A smart algorithm to match RFQs to vendors.
-   **Workflow:** A complete RFQ-to-payment lifecycle management module.
-   **Commercials:** Escrow payments, platform commissions, and multi-currency support.
-   **Dashboards:** Dedicated dashboards for buyers, vendors, and admins.
-   **Tech Stack:** React/Next.js frontend, Python (FastAPI) backend, and a PostgreSQL database (currently using MongoDB).

**User's preferred language**: English

**what currently exists?**
A full-stack application with a React frontend and FastAPI backend using MongoDB. The application is branded as **MachinoMatch** and supports JWT authentication for Buyer, Vendor, and Admin roles.

Key implemented features:
-   **Core Workflows:** RFQ matching, quotation lifecycle (submission, comparison, acceptance), and order management.
-   **Quote Negotiation:** A full-featured system allowing buyers to request modifications and vendors to accept, reject, or counter-offer.
-   **Notification System:** In-app notifications (bell icon, dropdown, dedicated page) and email alerts for key events.
-   **Role-Specific Pages:** Dedicated dashboards and pages for buyers (My RFQs, Received Quotes) and vendors (Matched RFQs).
-   **Admin Panel:** Comprehensive CRUD management of users, vendors, and machines, including the ability to create new users and vendors.
-   **UI/UX Features:** Vendor rating system, material supply options in RFQs, and detailed quote cards.
-   **Integrations:** GPT-5.2 for drawing analysis, Resend for emails, and a GSTIN API for vendor data auto-fill.
